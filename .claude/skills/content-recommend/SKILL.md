# 크로스 카테고리 추천

콘텐츠 추천 관련 코드를 다룰 때 자동으로 적용되는 스킬입니다.

## 트리거 조건

- `src/screens/Recommend/` 파일 수정 시
- `src/prompts/recommend*` 파일 수정 시
- `supabase/functions/recommend-content/` 수정 시

## 규칙

### 추천 원칙
- 카테고리 경계를 넘는 추천 가능 (영화 평론 → 책 추천)
- 추천 이유를 반드시 설명
- 사용자의 누적 취향 프로필 기반

### 추천 데이터
- 누적 평론 및 취향 분석 결과 활용
- 최근 평론에 더 높은 가중치
- 다양한 카테고리 균형 있게 추천

### UI 요소
- 추천 카드: 콘텐츠 정보 + 추천 이유
- 위시리스트 저장 기능
- 추천 새로고침 (다른 추천 보기)
- 카테고리 필터

# 평론 작성 인터뷰 플로우

평론 작성 관련 코드를 다룰 때 자동으로 적용되는 스킬입니다.

## 트리거 조건

- `src/screens/Review/` 파일 수정 시
- `src/prompts/interview*` 파일 수정 시
- `supabase/functions/generate-question/` 수정 시
- `supabase/functions/generate-review/` 수정 시

## 규칙

### 인터뷰 질문 생성
- 질문은 "보편적"이 아닌 해당 콘텐츠 **특화** 질문이어야 함
- 콘텐츠 메타데이터(장르, 감독, 시대 등)를 활용한 맥락적 질문
- 이전 답변을 반영한 후속 질문 생성

### UX 규칙
- 새끼질문 (후속 질문): 아래로 스크롤하여 표시
- 주제 전환 질문: 오른쪽 슬라이드 애니메이션
- 5개 이상 답변 시 "평론 미리보기" 버튼 활성화

### 평론 생성
- 인터뷰 답변을 종합하여 개인 평론 작성
- 사용자의 고유한 관점과 감상을 반영
- 평론 톤은 사용자 스타일에 맞춤

# 취향 분석 로직

취향 분석 관련 코드를 다룰 때 자동으로 적용되는 스킬입니다.

## 트리거 조건

- `src/screens/Analysis/` 파일 수정 시
- `src/prompts/analysis*` 파일 수정 시
- `supabase/functions/analyze-taste/` 수정 시

## 규칙

### 분석 원칙
- 정성적 서술 (스토리 형태) 필수
- 단순 통계, 키워드 나열, 태그 클라우드 금지
- 사용자의 취향을 하나의 이야기로 풀어서 설명
- 시간에 따른 취향 변화 추적

### 분석 데이터
- 누적 평론 데이터 기반
- 카테고리별, 기간별 분석
- 평론 텍스트에서 패턴 추출 (좋아하는 요소, 감정 반응 등)

### UI 표현
- 텍스트 중심의 서술형 UI
- 차트/그래프는 보조적 역할만
- 카테고리별 탭 또는 섹션 구분

# /plan — 기능 구현 계획 수립

특정 기능에 대한 구현 계획을 수립합니다.

## 사용법

```
/plan <기능 설명>
```

## 실행 내용

1. 기능 요구사항 분석 (`docs/feature-spec.md` 참조)
2. 영향받는 파일 및 컴포넌트 식별
3. 구현 단계 목록 작성
4. 필요한 DB 스키마 변경 사항 파악
5. 필요한 Edge Function 목록
6. 필요한 프롬프트 템플릿 목록
7. 테스트 계획

## 출력 형태

- 단계별 구현 계획 (체크리스트)
- 파일 생성/수정 목록
- 의존성 및 주의사항

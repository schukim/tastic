# /design-prompt — LLM 프롬프트 설계

Claude API에 사용할 프롬프트 템플릿을 설계합니다.

## 사용법

```
/design-prompt <프롬프트 목적>
```

## 실행 내용

1. 프롬프트 목적 분석
2. `src/prompts/` 에 프롬프트 템플릿 파일 생성
3. 시스템 프롬프트 + 유저 프롬프트 구조 설계
4. 변수 바인딩 (`{{variable}}`) 설정
5. 예시 입출력 작성
6. Edge Function과 연결 방법 안내

## 설계 규칙

- 질문은 보편적이 아닌 콘텐츠 특화
- 취향 분석은 정성적 서술, 키워드 나열 금지
- 추천은 크로스 카테고리 가능
- 한국어 기본, 다국어 지원 고려
- 프롬프트 변수는 `{{variable}}` 형식

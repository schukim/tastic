# /setup — 프로젝트 초기 셋업

프로젝트를 처음 시작할 때 실행합니다.

## 실행 내용

1. Expo 프로젝트 초기화 (TypeScript 템플릿)
2. 필수 패키지 설치 (react-navigation, zustand, nativewind, supabase-js 등)
3. `src/` 디렉토리 구조 생성
4. `supabase/` 디렉토리 구조 생성
5. TypeScript, ESLint, Prettier 설정
6. NativeWind (Tailwind) 설정
7. Supabase 클라이언트 초기화 코드 작성
8. React Navigation 기본 설정 (Bottom Tabs 5개)
9. i18n 기본 설정 (ko, en)
10. `.env.example` 기반 환경변수 안내

## 사전 조건

- Node.js 18+
- `.env` 파일에 Supabase 및 Anthropic API 키 설정

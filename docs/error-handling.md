# 오프라인 / 에러 상태 처리

## 개요

Tastic은 LLM 호출과 Supabase 연동에 네트워크가 필수이므로, 연결 불안정 시의 사용자 경험을 체계적으로 관리한다.

---

## 1. 네트워크 상태 감지

### 구현
- `@react-native-community/netinfo`를 사용하여 네트워크 상태를 전역으로 감지
- Zustand `networkStore`에서 `isConnected`, `isInternetReachable` 상태 관리

### 오프라인 진입 시
- 화면 상단에 얇은 배너 표시: "인터넷 연결이 없습니다" (빨간 배경, 텍스트 흰색)
- 배너는 연결 복구 시 자동으로 사라짐 (슬라이드업, 300ms)
- 네트워크가 필요한 액션(LLM 호출, 저장 등)의 버튼을 비활성화 상태로 전환

---

## 2. 인터뷰 중 에러 처리 (가장 중요)

인터뷰는 사용자가 가장 많은 시간을 투자하는 플로우이므로, 데이터 유실 방지가 최우선.

### 2-1. 임시 저장 (Auto-draft)

#### 저장 시점
- 사용자가 답변을 제출할 때마다 로컬(AsyncStorage)에 자동 저장
- 저장 데이터: 작품 정보, conversation_history, 현재 질문 번호, 마지막 저장 시각

#### 복구 플로우
- 앱 재시작 시 미완성 인터뷰 draft가 있는지 확인
- draft 존재 시 → 평론(홈) 탭 진입 시 다이얼로그 표시:
  - "이전에 진행 중이던 '{작품 제목}' 인터뷰가 있습니다."
  - 버튼 2개: "이어서 하기" / "새로 시작"
- "이어서 하기" → 인터뷰 화면(화면 3)으로 복귀, 이전 대화 복원
- "새로 시작" → draft 삭제, 홈 화면(화면 1)으로

#### draft 만료
- 7일 이상 된 draft는 앱 시작 시 자동 삭제

### 2-2. 질문 생성 실패

#### 원인
- 네트워크 끊김
- Edge Function 타임아웃
- LLM 응답 파싱 실패

#### 처리
- 입력 영역 아래에 인라인 에러 메시지: "질문을 불러오지 못했어요."
- "다시 시도" 버튼 표시
- 재시도 시 동일한 conversation_history로 재요청
- 3회 연속 실패 시: "네트워크 상태를 확인해주세요. 진행 중인 내용은 자동 저장되어 있습니다." + "나중에 이어하기" 버튼 (draft 저장 후 홈으로 복귀)

### 2-3. 평론 생성 실패

#### 처리
- 로딩 상태에서 에러 발생 시 → 평론 완성 화면(화면 4) 대신 에러 상태 표시
- "평론을 생성하지 못했어요. 다시 시도할까요?"
- 버튼 2개: "다시 생성" / "인터뷰로 돌아가기"
- 인터뷰 대화 데이터는 유지되므로 언제든 재생성 가능

---

## 3. 저장 실패 (Supabase)

### 평론 저장 실패
- 저장 버튼 터치 → 네트워크/서버 에러 발생 시:
  - 토스트: "저장에 실패했습니다. 다시 시도해주세요."
  - 평론 데이터는 로컬(AsyncStorage)에 임시 저장
  - 저장 버튼 다시 활성화 (재시도 가능)
- 앱 재시작 시 미저장 평론이 있으면:
  - 자동으로 서버 저장 재시도 (백그라운드)
  - 성공 시 토스트: "이전에 저장하지 못한 평론이 저장되었습니다."
  - 실패 시 마이페이지에 "미저장 평론 N개" 알림 표시

### 프로필/설정 저장 실패
- 토스트: "변경사항을 저장하지 못했습니다."
- 로컬에 변경사항 캐시 → 네트워크 복구 시 자동 동기화

---

## 4. 분석/추천 에러 처리

### 취향 분석 실패
- 로딩 애니메이션 중 에러 발생 시:
  - 로딩 UI를 에러 상태로 전환
  - "분석을 완료하지 못했어요."
  - "다시 분석하기" 버튼
  - 이전 분석 결과가 있으면 그대로 유지 (새 결과로 덮어쓰지 않음)

### 추천 실패
- 스켈레톤 카드가 에러 상태 카드로 전환
- "추천을 불러오지 못했어요. 다시 시도해주세요."
- 입력창 다시 활성화

---

## 5. 인증 에러

### 토큰 만료
- Supabase 클라이언트가 자동 갱신 처리
- 갱신 실패 시: 로그인 화면으로 이동 + "세션이 만료되었습니다. 다시 로그인해주세요."
- 진행 중이던 인터뷰가 있으면 draft로 자동 저장 후 이동

### 인증 필요 화면 접근
- 비로그인 상태에서 보호된 화면 접근 시 → 로그인 화면으로 리다이렉트
- 로그인 완료 후 원래 화면으로 복귀

---

## 6. Edge Function 타임아웃

### 기본 타임아웃
- 질문 생성: 15초
- 평론 생성: 30초 (긴 대화 기반이므로 여유)
- 취향 분석: 30초
- 추천: 20초
- 작품 검색: 10초

### 타임아웃 발생 시
- 각 기능별 에러 처리 플로우를 따름 (위 섹션 참조)
- 타임아웃은 1회 자동 재시도 후 사용자에게 에러 표시

---

## 7. 에러 메시지 톤

### 원칙
- 기술 용어 사용 금지 (HTTP 코드, timeout, server error 등)
- 사용자 탓으로 돌리지 않음
- 항상 다음 액션을 제시
- 짧고 친근한 톤

### 예시
| 상황 | 메시지 |
|------|--------|
| 네트워크 끊김 | "인터넷 연결이 없습니다" |
| 질문 생성 실패 | "질문을 불러오지 못했어요" |
| 평론 저장 실패 | "저장에 실패했습니다. 다시 시도해주세요" |
| 분석 실패 | "분석을 완료하지 못했어요" |
| 서버 점검 | "잠시 서비스를 이용할 수 없습니다" |

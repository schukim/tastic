# Critiq 기능 명세서

## 개요

Critiq는 문화 콘텐츠(영화, 음악, 책, 미술, 전시, 공연) 감상 후 LLM 기반 인터뷰를 통해 개인 평론을 작성하고, 취향을 분석·추천하는 모바일 앱입니다.

## 콘텐츠 카테고리

| 카테고리 | 아이콘 | 메타데이터 |
|----------|--------|------------|
| 영화 | 🎬 | 제목, 감독, 장르, 개봉연도, 러닝타임 |
| 음악 | 🎵 | 곡/앨범명, 아티스트, 장르, 발매연도 |
| 책 | 📚 | 제목, 저자, 장르, 출판연도, 페이지수 |
| 미술 | 🎨 | 작품명, 작가, 매체, 제작연도 |
| 전시 | 🏛️ | 전시명, 기획자/기관, 장소, 기간 |
| 공연 | 🎭 | 공연명, 연출/출연, 장르, 장소 |

## 탭별 기능 상세

### 1. 평론 (홈, 중앙 탭) ✍️

메인 기능으로, LLM 인터뷰를 통해 평론을 작성합니다.

#### 플로우
1. **콘텐츠 선택**: 카테고리 선택 → 콘텐츠 정보 입력 (제목 등)
2. **인터뷰 시작**: LLM이 해당 콘텐츠에 특화된 질문 생성
3. **대화형 응답**: 사용자가 질문에 답변, 후속 질문 이어짐
4. **미리보기**: 5개 이상 답변 시 "평론 미리보기" 버튼 활성화
5. **평론 생성**: LLM이 답변을 종합하여 개인 평론 생성
6. **수정 및 저장**: 사용자가 평론 수정 후 저장

#### 인터뷰 UX 규칙
- 새끼질문 (후속 질문): 아래로 스크롤하여 표시
- 주제 전환 질문: 오른쪽 슬라이드 애니메이션
- 질문은 보편적이 아닌 **해당 콘텐츠 특화** 질문이어야 함

### 2. 히스토리 📋

과거 작성한 평론을 캘린더와 리스트로 탐색합니다.

#### 기능
- 캘린더 뷰: 날짜별 평론 작성 현황 표시
- 리스트 뷰: 최신순/카테고리별 정렬
- 평론 상세 보기
- 검색: 제목, 카테고리, 키워드 검색
- 필터: 카테고리별, 기간별

### 3. 추천 💡

취향 기반으로 크로스 카테고리 콘텐츠를 추천합니다.

#### 기능
- 누적 평론 데이터 기반 추천
- 카테고리 경계를 넘는 추천 (예: 영화 평론 → 책 추천)
- 추천 이유 설명 (왜 이 콘텐츠를 추천하는지)
- 추천 콘텐츠 저장 (위시리스트)
- 추천 새로고침

### 4. 분석 📊

누적 평론 기반으로 정성적 취향 분석을 제공합니다.

#### 기능
- 취향 프로필: 정성적 서술 (스토리 형태)
- 취향 변화 추적: 시간에 따른 취향 변화
- 카테고리별 분석
- 단순 통계/키워드 나열 금지 — 서술형 분석

### 5. 마이 👤

프로필, 설정, 구독 관리.

#### 기능
- 프로필 편집
- 알림 설정
- 구독 관리
- 언어 설정 (한국어/영어)
- 데이터 내보내기
- 로그아웃 / 회원탈퇴

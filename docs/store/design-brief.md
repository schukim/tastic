# Tastic 스토어 자산 — 클로드 디자인 핸드오프

이 문서는 두 부분이다.
- **Part 1 (진행 방법)**: 네가 읽는 부분 — 자산을 어떻게 받아 마무리할지.
- **Part 2 (디자인 브리프)**: `===== 핸드오프 시작 =====` 아래를 **통째로 복사해 클로드 디자인에게** 전달.

---

# Part 1. 진행 방법 (플랜)

### 단계
1. **실제 앱 스크린샷 확보(권장)**
   스토어 스크린샷은 실제 화면을 프레임에 넣는 게 가장 정확하다. iOS 시뮬레이터/안드로이드 에뮬레이터에서 아래 6개 화면을 캡처(1080×1920 이상, 상태바 깔끔하게).
   - 캡처가 어려우면: 브리프에 각 화면 구성을 적어뒀으니 클로드 디자인이 **목업으로 재현** 가능. 단 실제 캡처보다 디테일이 다를 수 있음.
2. **앱 아이콘 원본 첨부**: `tastic/assets/icon.png`를 클로드 디자인에게 함께 전달(512×512 변환·기능그래픽에 활용).
3. **Part 2를 복사해 클로드 디자인에게 전달** + (있으면) 캡처 이미지·icon.png 첨부.
4. **산출물 검수**: 아래 Play 규격 체크리스트로 확인.
5. **Play Console 업로드**: 그래픽 → 스크린샷 → 기능그래픽 순.

### Play 규격 체크리스트
- [ ] 앱 아이콘: 512×512 PNG(32-bit, 알파)
- [ ] 기능 그래픽: 1024×500 PNG/JPG (텍스트는 가장자리 안쪽 안전영역)
- [ ] 폰 스크린샷: 2~8장, 세로 9:16 권장(1080×1920), PNG/JPG
- [ ] ko/en 두 세트(스크린샷 오버레이 문구 언어별)
- [ ] 각 스크린샷 1개 헤드라인만(과한 텍스트 금지)

### 산출물 요청 목록 (클로드 디자인이 만들 것)
1. 기능 그래픽 1장 (ko, en 각 1 = 2장)
2. 폰 스크린샷 6장 (ko 6 + en 6 = 12장)
3. (선택) 앱 아이콘 512×512 정리본

# Part 2. 디자인 브리프

```
===== 핸드오프 시작 — 아래 전체를 클로드 디자인에게 전달 =====

# Tastic 앱스토어(Google Play) 비주얼 자산 디자인 요청

## 앱 소개
Tastic은 영화·음악·책·미술·시리즈 감상 후 AI 인터뷰를 통해 개인 평론을 쓰고,
취향을 분석하고, 카테고리를 넘나드는 추천을 받는 "문화 감상 기록" 모바일 앱이다.
감성: 차분하고 사색적이며, 종이에 잉크로 쓴 듯한 문학적 무드.

## 브랜드 키트 (반드시 준수)
- 무드: warm paper & ink, 미니멀, 문학적, 고요함. 화려한 그라데이션·네온·이모지 남발 금지.
- 컬러 (HEX):
  - 잉크(메인 텍스트/포인트): #221F1A   진한 잉크: #0F0D0A
  - 배경 종이색: #F8F6F1   카드/밝은면: #FDFCF9   구분선: #EAE7E0
  - 본문 텍스트: #1E1B17   보조 텍스트: #6B6358   흐린 텍스트: #9C9589
  - 카테고리 악센트(절제된 잉크톤): 영화 #5C2E2E / 음악 #2E3D4F / 책 #3D4A2E / 미술 #5C4A2E
- 폰트: Pretendard 또는 Noto Sans KR (한글), 영문은 동일 계열의 깔끔한 산세리프.
  제목은 굵게, 본문은 가볍게. 자간 넉넉히.
- 톤 키워드: 따뜻한, 절제된, 손글씨 같은 여백, 종이 질감(아주 은은하게)

## 산출물 1 — 기능 그래픽 (Feature Graphic)
- 규격: 1024 x 500 px, PNG.
- 구성: 종이색(#F8F6F1) 배경. 좌측 또는 중앙에 앱명 "Tastic"을 잉크색(#221F1A)으로 크게,
  그 아래 태그라인. 우측/주변에 영화·음악·책·미술·시리즈를 상징하는
  미니멀 라인 아이콘 5개를 잉크 선화로 은은하게 배치.
- 태그라인:
  - ko 버전: "감상을 평론으로"
  - en 버전: "Turn impressions into reviews"
- 텍스트는 안전영역(가장자리 64px 안쪽) 유지. 과밀 금지, 여백 충분히.
- ko/en 2장 제작.

## 산출물 2 — 폰 스크린샷 6장 (각 ko/en)
- 규격: 1080 x 1920 px(세로 9:16), PNG.
- 공통 레이아웃: 상단에 헤드라인(한 줄) + 그 아래 앱 화면(실제 캡처를 폰 프레임에
  넣거나, 캡처 미제공 시 아래 "화면 설명"대로 목업). 배경은 종이색 계열,
  카테고리 악센트를 한 컷마다 하나씩 은은하게 변주.
- 텍스트는 헤드라인 1줄만. 작은 보조문구 1줄까지 허용.

각 컷의 헤드라인과 화면:

1) 평론 작성(AI 인터뷰)
   - ko: "질문에 답하면, 평론이 됩니다"   en: "Answer a few questions — get your review"
   - 화면: 채팅형 인터뷰. 상단에 작품 제목, 인터뷰어 질문 말풍선과 사용자가 답하는 입력창.

2) 완성된 평론
   - ko: "당신의 언어로 남는 한 편"   en: "A piece, in your own words"
   - 화면: 완성된 평론 본문(제목 + 문단 글). 차분한 리더뷰.

3) 취향 분석
   - ko: "취향을 통계가 아닌 이야기로"   en: "Your taste, told as a story"
   - 화면: 서술형 취향 분석 글(문단). 키워드 나열이 아닌 문장.

4) 크로스 카테고리 추천
   - ko: "영화에서 책으로, 경계 없는 추천"   en: "Recommendations without borders"
   - 화면: 추천 카드 리스트. 서로 다른 카테고리(영화·책·음악) 카드가 섞여 있음.

5) 히스토리(캘린더)
   - ko: "감상의 기록이 쌓입니다"   en: "Your impressions, collected"
   - 화면: 월 캘린더 + 날짜에 평론 점/리스트.

6) 시작 유도(CTA)
   - ko: "지금, 첫 평론을 남겨보세요"   en: "Write your first review today"
   - 화면: 홈(평론 작성) 진입 화면 또는 멤버십 카드. 깔끔한 시작 버튼 강조.

## 산출물 3 (선택) — 앱 아이콘
- 첨부된 icon.png를 512x512 PNG(32-bit, 알파)로 정리. 디자인 변경 없이 규격 맞춤만.

## 출력 형식
- 파일명: feature-graphic-ko.png / feature-graphic-en.png /
  screenshot-01-ko.png ... screenshot-06-ko.png / (en 동일)
- 각 산출물은 위 규격 px 정확히. 텍스트 한/영 철자 정확히(오타 금지).

===== 핸드오프 끝 =====
```

## 참고 (네가 알아둘 것)
- 실제 화면 톤이 궁금하면 앱 색은 위 HEX가 정확한 값(tailwind 토큰 기준).
- 스크린샷 오버레이 문구는 `play-store-listing.md`의 카피와 톤을 맞춰뒀다.
- iOS도 낼 때는 App Store 스크린샷 규격(예: 6.7" 1290×2796)이 달라 별도 리사이즈 필요 — 그때 같은 브리프에 규격만 바꿔 재요청.

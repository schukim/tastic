# 평론(홈) 탭 — UX 워크플로우

## 화면 1: 메인 진입

### 초기 상태
- 화면 중앙에 "~님, 오늘은 무엇을 감상하셨나요?" 문구
- 문구 아래에 제목 입력창 (placeholder: "작품 제목을 입력하세요")
- 입력창 외에는 빈 화면 (집중 유도)

### 입력창 터치 시 전환
- **애니메이션**: 중앙 문구가 화면 상단으로 부드럽게 올라감 (300ms, ease-out)
- 입력창이 상단 문구 바로 아래로 이동
- 입력창 아래에 추가 필드가 페이드인으로 나타남:
  1. **제목** (텍스트 입력, 이미 활성화 상태)
  2. **카테고리** (칩 선택 UI: 영화 / 음악 / 책 / 미술 / 전시 / 공연)
  3. **감상 일자** (날짜 피커, 기본값: 오늘)
- 모든 항목 입력 완료 시 하단에 "다음" 버튼 활성화 (비활성→활성 색상 전환)

## 화면 2: 작품 확인

### 전환 방식
- "다음" 터치 시 오른쪽에서 슬라이드인 (stack navigation push)

### 데이터 소스
- 외부 DB/API 없이 **LLM(Claude API)이 작품을 식별**하여 후보를 반환
- Edge Function `verify-content`를 호출하여 제목+카테고리 기반으로 검색
- 상세: `docs/prompt-strategy.md` > "1. 작품 검색 — verify-content" 참조

### 화면 구성
- 상단: "이 작품이 맞나요?"
- **로딩 상태**: 스켈레톤 카드 1~3개 (shimmer 애니메이션)
- 작품 카드 리스트 (세로 스크롤):
  - 각 카드: 작품 제목, 연도, 감독/작가/아티스트, confidence 뱃지(high/medium)
  - 선택된 카드: 테두리 하이라이트 (primary color)
- 작품이 1개 + confidence high면 해당 카드가 미리 선택된 상태
- 검색 결과 없을 때: "작품을 찾지 못했어요. 직접 입력할게요" 옵션
- **카테고리가 전시/공연일 때**: LLM이 식별하지 못할 가능성이 높으므로 "직접 입력" 옵션을 상단에 우선 노출
- 하단: "다음" 버튼 (작품 선택 또는 직접 입력 완료 시 활성화)

## 화면 3: 인터뷰 (질문-답변)

### 전환 방식
- 오른쪽에서 슬라이드인

### 초기 상태
- 상단: 작품 제목 + 카테고리 아이콘 (고정 헤더)
- 진행 표시: "질문 1" (답변 수 카운터)
- LLM 생성 첫 질문이 카드 형태로 표시
- 질문 카드 아래: 답변 입력 영역 (멀티라인 텍스트)
- 하단: "다음" 버튼

### 답변 후 다음 질문 전환

#### 새끼 질문 (drill-down) — 이전 답변을 깊이 파고드는 질문
- **전환 애니메이션**: 현재 Q&A가 위로 올라가고, 새 질문이 아래에서 슬라이드업 (세로 스크롤 느낌)
- 이전 Q&A는 위로 스크롤하면 다시 볼 수 있음 (히스토리 형태)
- 시각적 연결: 이전 질문과 같은 색상 계열, 들여쓰기 or 연결선으로 관계 표현

#### 주제 전환 (pivot) — 새로운 관점의 질문
- **전환 애니메이션**: 현재 화면이 왼쪽으로 슬라이드아웃, 새 질문이 오른쪽에서 슬라이드인 (가로 페이지 전환 느낌)
- 상단 진행 표시에 새로운 주제 섹션임을 표시
- 시각적 구분: 다른 색상 계열, 구분선

### 5개 답변 이후
- **"평론 미리보기" 버튼** 등장 (하단에 페이드인, "다음" 버튼 옆)
- 버튼 터치 시 바텀시트 or 모달로 평론 초안 표시
- 미리보기 닫으면 질문 계속 이어감
- "답변 종료하기" 버튼도 함께 노출

### 전체 인터뷰 중 공통
- 이전 Q&A 히스토리는 위로 스크롤하여 확인 가능
- 상단 헤더의 질문 카운터 실시간 업데이트
- 뒤로가기 시 "진행 중인 인터뷰를 저장하고 나갈까요?" 확인 다이얼로그

## 화면 4: 평론 완성

### 전환 방식
- "답변 종료하기" 터치 시 전체 화면 전환 (fade or slide-up)

### 화면 구성
- 상단: 작품 제목 + "평론 작성"
- LLM이 생성한 평론 초안이 편집 가능한 텍스트 영역에 표시
- 텍스트 영역: 충분한 높이, 자유롭게 수정 가능
- 글자 수 카운터 (우하단)
- 하단 버튼 2개:
  - "다시 생성" (LLM에게 재생성 요청, 기존 답변 기반)
  - "저장하기" (확정 후 저장)
- 저장 완료 시: 성공 토스트 메시지 + 홈으로 복귀 (또는 히스토리로 이동 선택)

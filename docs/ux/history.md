# 히스토리 탭 — UX 워크플로우

## 화면 구성 (2개 구역, 세로 분할)

### 상단 구역: 캘린더

#### 레이아웃
- 월 표시 헤더: "2026년 4월" + 좌우 화살표 (이전/다음 달)
- 요일 헤더: 일 / 월 / 화 / 수 / 목 / 금 / 토
- 날짜 그리드: 6주 × 7일

#### 인터랙션
- **좌우 스와이프**: 이전/다음 달 이동 (swipeable 제스처, 300ms 슬라이드)
- **화살표 버튼**: 좌우 스와이프와 동일 기능
- **오늘 날짜**: 원형 배경 하이라이트

#### 평론 기록 표시
- 평론이 있는 날짜에 날짜 숫자 아래 **작은 색상 점** 표시
- 점의 색상 = 카테고리 색상 (사용자 커스터마이징 가능):
  - 기본값: 영화 빨강, 음악 파랑, 책 초록, 미술 노랑, 전시 보라, 공연 분홍
- 하루에 여러 카테고리 평론 → 점 여러 개 가로 나열 (최대 3개, 초과 시 "+N")
- **날짜 터치 시**: 해당 날짜의 평론 팝업 표시 (아래 "평론 팝업" 참조)
- 평론 없는 날짜 터치 시: 반응 없음

### 하단 구역: 평론 리스트

#### 레이아웃
- 세로 스크롤 리스트
- 각 항목:
  - 좌측: 카테고리 색상 아이콘 (원형)
  - 중앙: 작품 제목 (1줄) + 감상 날짜 (서브텍스트, 회색)
  - 우측: 평론 작성일 (상대 시간: "3일 전", "1주 전")
- 정렬: 작성일 기준 최신순 (위에서 아래)

#### 인터랙션
- **항목 터치**: 평론 팝업 표시
- **스크롤**: 일반 세로 스크롤 (캘린더 구역과 독립)
- 리스트가 비어있을 때: "아직 작성한 평론이 없어요" + 평론 탭 이동 유도 버튼

## 평론 팝업 (공통)

### 진입
- 캘린더 날짜 터치 또는 리스트 항목 터치로 진입
- **전환 애니메이션**: 바텀시트 (하단에서 슬라이드업, 화면 70~85% 높이)
- 배경 딤 처리 (반투명 오버레이)

### 팝업 구성
- **헤더**: 작품 제목 + 카테고리 아이콘 + 감상 날짜
- **본문**: 평론 텍스트 (읽기 전용 상태, 스크롤 가능)
- **하단 액션 바**:
  - 수정 버튼 (연필 아이콘): 터치 시 텍스트가 편집 가능 상태로 전환 + "저장" 버튼 나타남
  - 복사 버튼 (복사 아이콘): 터치 시 클립보드에 복사 + "복사되었습니다" 토스트
- **닫기**: 하단으로 스와이프 다운 또는 배경 터치

### 수정 모드
- 수정 버튼 터치 → 텍스트 영역이 편집 가능으로 전환
- 키보드가 올라오면 팝업 높이 자동 조절
- 하단 버튼이 "취소" + "저장"으로 변경
- 저장 시 DB 업데이트 + "수정되었습니다" 토스트

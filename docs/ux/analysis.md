# 분석 탭 — UX 워크플로우

## 상태 1: 최초 진입 (분석 없음)

### 화면 구성
- 화면 중앙: 일러스트 또는 아이콘 (돋보기 + 하트 등)
- 텍스트: "아직 분석된 취향이 없어요. 취향을 분석해볼까요?"
- CTA 버튼: "취향 분석하기" (primary color, 중앙 정렬)

### 분석 불가 조건
- 평론이 3개 미만일 때:
  - "취향 분석을 위해 평론이 더 필요해요. (현재 N개 / 최소 3개)"
  - 버튼 비활성화 상태
  - 평론 탭 이동 유도 링크

---

## 상태 2: 분석 진행 중

### 전환
- "취향 분석하기" 터치 시 시작
- **로딩 애니메이션**: 화면 중앙에 분석 진행 인디케이터
  - "평론을 읽고 있어요..." → "패턴을 찾고 있어요..." → "취향을 정리하고 있어요..."
  - 3단계 텍스트가 2초 간격으로 전환 (페이드)
- 전체 소요 시간: 약 5~10초

---

## 상태 3: 분석 완료

### 화면 구성

#### 상단 고정 영역
- "취향 다시 분석하기" 텍스트 버튼 (우상단)
- 새 평론이 추가된 경우: 버튼 옆에 알림 뱃지 ("새 평론 N개 반영 가능")

#### 취향 프로파일 영역
- 카드 형태의 프로파일 영역
- 제목: "~님의 감상 프로파일"
- 본문: 정성적 서술 문장 5~8개
  - 각 문장 앞에 "·" 불릿
  - 문장당 30자 내외, 간결하게
  - 예시:
    ```
    · 해체된 구조와 서사를 통해 표현의 새로운 가능성을 탐색합니다.
    · 아이러니와 충돌을 통해 메시지를 전달하는 작품을 선호합니다.
    · 시각적 아름다움보다 질감과 분위기의 일관성에 민감합니다.
    · 작가의 의도보다 자신이 느낀 감정의 진정성을 더 중시합니다.
    ```
- 하단: 분석 일시 + 반영된 평론 수 (서브텍스트)

#### 추천 유도 영역 (하단)
- 구분선
- 텍스트: "~님은 ~~한 ~~(영화/음악 등)을 좋아할 것 같아요. 추천해드릴까요?"
  - 이 문구 자체도 LLM이 생성 (취향 분석 결과 기반)
  - 터치 가능 영역 (전체가 버튼)
- **터치 시**: 추천 탭으로 이동 + "~~한 ~~ 추천해줘" 프롬프트 자동 입력 + 자동 실행

## 재분석 플로우

### 트리거
- "취향 다시 분석하기" 터치

### 동작
- 이전 분석 결과는 유지한 채 로딩 오버레이 표시
- LLM에 전달: 이전 분석 결과 + 이후 추가된 평론들
- 완료 시: 새 분석 결과로 교체 (페이드 트랜지션)
- 추천 유도 문구도 새 분석 기반으로 갱신

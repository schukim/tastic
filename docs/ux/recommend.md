# 추천 탭 — UX 워크플로우

## 화면 구성

### 초기 상태
- 상단: "어떤 콘텐츠를 찾고 있나요?"
- 프롬프트 입력창 (placeholder: "예: 몽환적인 분위기의 영화 추천해줘")
- 입력창 아래: 빠른 추천 칩 버튼들 (선택적)
  - "영화 추천", "책 추천", "음악 추천", "새로운 장르 도전"
- 이전 추천 결과가 있으면 아래에 히스토리로 표시

### 추천 요청 시
- 입력 후 전송 버튼 터치 (또는 칩 터치)
- **로딩 상태**: 입력창 아래에 스켈레톤 카드 3~5개 (shimmer 애니메이션)
- 로딩 중 입력창 비활성화

### 추천 결과 표시
- 로딩 완료 시 스켈레톤이 실제 카드로 교체 (페이드인, 위에서 아래로 순차)
- 각 추천 카드:
  - 카테고리 아이콘 + 뱃지 (좌상단)
  - 작품 제목 (메인 텍스트, 볼드)
  - 감독/작가/아티스트 + 연도 (서브텍스트)
  - 추천 이유 1~2문장 (본문, 사용자 취향과의 연결)
  - 카드 터치 시: 확장되어 추천 이유 전문 표시 (accordion)

### 추천 없는 경우 (평론 부족)
- "추천을 위해 평론이 더 필요해요. 최소 3개의 평론을 작성해주세요."
- 평론 탭 이동 버튼

### 분석 탭에서 넘어온 경우
- 분석 탭 하단의 추천 유도 문구 터치 시:
  - 추천 탭으로 전환 + 입력창에 "~~한 ~~ 추천해줘" 자동 입력
  - 자동으로 추천 요청 실행 (사용자가 별도 전송 불필요)

# 회원가입 / 로그인 — UX 워크플로우

## 로그인 화면

### 화면 구성
- 상단: 앱 로고 + 앱 이름 "Critiq"
- 이메일 입력 필드
- 비밀번호 입력 필드 (비밀번호 보기 토글)
- "로그인" 버튼 (primary, 전체 너비)
- 구분선: "또는"
- 소셜 로그인 버튼 (Apple / Google)
- 하단: "계정이 없으신가요? 회원가입" 링크

### 에러 처리
- 이메일/비밀번호 오류: 필드 하단에 빨간 텍스트 표시
- 네트워크 오류: 토스트 메시지

---

## 회원가입 화면

### 단계 1: 계정 정보
- 이메일 입력 (실시간 형식 검증)
- 비밀번호 입력 (최소 8자, 강도 인디케이터)
- 비밀번호 확인
- "다음" 버튼

### 단계 2: 프로필 설정
- 닉네임 입력 (중복 확인)
- 프로필 이미지 (선택사항, 기본 아바타 제공)
- 관심 카테고리 선택 (최소 1개): 영화 / 음악 / 책 / 미술 / 전시 / 공연
- "시작하기" 버튼

### 완료
- 가입 성공 → 메인(평론 탭)으로 자동 이동

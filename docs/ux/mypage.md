# 마이페이지 탭 — UX 워크플로우

## 화면 구성 (세로 스크롤, 섹션별 그룹)

### 프로필 섹션 (최상단)
- 프로필 이미지 (원형, 터치 시 이미지 변경)
- 닉네임 (터치 시 인라인 편집)
- 가입일 또는 작성 평론 수 (서브텍스트)

### 관심 카테고리 섹션
- 섹션 제목: "관심 카테고리"
- 카테고리 칩 목록 (토글 선택): 영화 / 음악 / 책 / 미술 / 전시 / 공연
- 선택된 칩: primary color 배경
- 변경 시 즉시 저장 (별도 저장 버튼 없음)

### 앱 설정 섹션
- 섹션 제목: "설정"
- **다크모드**: 토글 스위치 (즉시 반영, 전체 앱 테마 전환)
- **언어 설정**: 현재 언어 표시 + 터치 시 바텀시트로 선택 (한국어 / English)

### 구독 섹션
- 섹션 제목: "구독"
- 현재 플랜 표시: "무료 플랜" 또는 "프리미엄 플랜"
- 무료 플랜일 때: "프리미엄으로 업그레이드" 버튼 + 혜택 요약
- 프리미엄일 때: 다음 결제일 + "구독 관리" 링크

### 계정 관리 섹션
- **로그아웃**: 터치 시 확인 다이얼로그 → 로그인 화면으로 이동
- **계정 삭제**: 터치 시 경고 다이얼로그 ("모든 데이터가 삭제됩니다") → 비밀번호 재입력 → 삭제 처리
